#Couriway Speedruns

Couriway Speedruns is a program run with Java code that tracks the most important parts of Couriway's journey to 100,000 Minecraft speedruns. This includes time entering the nether and end, the seed, the amount of deaths(excluding hunger resets) time of the run, run number, time paused each run, blaze killed to blaze rods dropped ratio, and more! (Runs 1 - 6716)

###Overview

1. A user chooses which run they want to evaluate.
2. The program runs through all the runs, finding the run that the user wanted to evaluate.
3. The user then decides what data to look at, and asks the program to give that data.
4. The program goes through the run found earlier, and find the data the user requested.
5. The program prints out the data that the user requested.

###Example

1. User Chooses run number 1234.
2. PICTURE OF PROGRAM ASKING WHAT RUN USER WANTS
3. The program runs until it finds run 1234
4. PICTURE OF PROGRAM ASKING WHAT DATA USER WANTS
5. The user decided to look at the blaze rods dropped to blaze killed ratio
6. The program goes through run 1234, finding 7 blaze rods were dropped, and 13 were killed.
7. The programs runs said code, and returns 0.53846153846, the decimal equivalent if 7/13.
8. PICTURE OF PROGRAM SHOWING USER OUTPUT

###Installation

All you have to do to install and run Couriway Speedruns is to clone the repository and run it with java!

###Usage

1. Type in which run you want to evaluate
2. Type in what data you want to look at
3. Your data will be given to you
